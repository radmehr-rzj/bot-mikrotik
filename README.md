# bot-mikrotik

ربات تلگرام کامل برای فروش و مدیریت خودکار اکانت‌های VPN (L2TP / OpenVPN) از
طریق **User Manager** میکروتیک (RouterOS 7.x)، با پرداخت کارت‌به‌کارت و تایید
ادمین، پنل مدیریت کامل، بک‌آپ/ریستور، و آموزش اتصال خودکار برای مشتری.

## ویژگی‌ها

- 🛒 خرید خودکار با انتخاب تعرفه (۱/۲ ماهه)، امکان افزودن «کاربر اضافه» (دستگاه همزمان بیشتر) با قیمت جداگانه
- 💳 پرداخت کارت‌به‌کارت با ارسال رسید و تایید/رد توسط ادمین (با دکمه‌های شیشه‌ای)
- ⚙️ پنل مدیریت کامل از داخل خود ربات (`/settings`) — همه چیز از شماره کارت تا اطلاعات اتصال میکروتیک، بدون نیاز به ویرایش فایل روی سرور
- 📦 بخش «اکانت‌های من» برای مشتری — مشاهده اکانت‌های خریداری‌شده و وضعیت زنده‌شان
- 🧩 آموزش اتصال L2TP/OpenVPN که خودکار بعد از خرید برای مشتری ارسال می‌شود (متن آن هم کاملاً قابل ویرایش است)
- 💾 بک‌آپ/ریستور کامل (دستی و خودکار روزانه، مستقیم در تلگرام)
- 📊 آمار کاربران و اطلاع‌رسانی ورود کاربر جدید به ادمین
- 🔐 دسترسی مدیریتی محدود به یک ادمین مشخص؛ خرید برای عموم کاربران باز است

## نصب سریع

روی یک سرور اوبونتو/دبیان (به‌عنوان root یا با `sudo`):

```bash
git clone https://github.com/radmehr-rzj/bot-mikrotik.git
cd bot-mikrotik
sudo bash install.sh
```

اسکریپت نصب فقط دو چیز از شما می‌پرسد:

1. **توکن ربات** — از [@BotFather](https://t.me/BotFather) در تلگرام بسازید (دستور `/newbot`).
2. **آیدی عددی تلگرام شما** (به‌عنوان ادمین) — از [@userinfobot](https://t.me/userinfobot) بگیرید.

بقیه مراحل (نصب پایتون، ساخت virtualenv، نصب کتابخانه‌ها، راه‌اندازی سرویس
systemd) کاملاً خودکار انجام می‌شود.

## تنظیمات بعد از نصب (همه از داخل خود ربات)

بعد از نصب، در تلگرام به ربات خودتان بروید:

1. `/start` را بزنید.
2. `/settings` را بزنید و این موارد را وارد کنید:
   - آی‌پی/هاست، یوزر و پسورد API میکروتیک
   - نام پروفایل‌های User Manager برای تعرفه ۱ و ۲ ماهه (باید از قبل در میکروتیک ساخته شده باشند)
   - شماره کارت و نام صاحب کارت
   - قیمت هر تعرفه و قیمت کاربر اضافه
   - آیدی پشتیبانی، آدرس سرور برای مشتری، و بقیه موارد

هیچ‌کدام از این‌ها نیاز به ویرایش فایل روی سرور یا ری‌استارت سرویس ندارد.

### پیش‌نیاز روی خود میکروتیک

- پکیج `user-manager` باید نصب باشد (`/system package print`).
- API باید فعال باشد: `/ip service enable api` (و ترجیحاً محدود به IP سرور ربات).
- حداقل یک یوزر API با دسترسی محدود بسازید:
  ```
  /user group add name=api-bot-group policy=api,read,write,test,!local,!telnet,!ssh,!ftp,!reboot,!password,!policy,!winbox,!web,!sniff,!sensitive,!romon
  /user add name=YOUR_BOT_USER password=YOUR_STRONG_PASSWORD group=api-bot-group
  ```
- پروفایل‌های User Manager مورد نظر (مثلاً `30Day`, `60Day`) را از قبل بسازید.
- برای فعال شدن L2TP/OpenVPN از طریق User Manager، RADIUS را در PPP فعال کنید:
  ```
  /ppp aaa set use-radius=yes
  /user-manager router add name=local-router address=127.0.0.1 shared-secret=YOUR_SECRET service=ppp
  /radius add service=ppp address=127.0.0.1 secret=YOUR_SECRET
  ```

## فایل کانفیگ OpenVPN

اگر می‌خواهید بعد از هر خرید یک فایل `.ovpn` هم خودکار برای مشتری ارسال شود،
با دستور `/setovpn` در ربات، فایل کانفیگ سرویس OpenVPN خودتان را ارسال کنید.
تا وقتی این فایل تنظیم نشده، این بخش نادیده گرفته می‌شود (نه خطا).

## دستورات ادمین

| دستور | توضیح |
|---|---|
| `/settings` | پنل مدیریت کامل تنظیمات |
| `/listvpn` | لیست یوزرهای موجود |
| `/delvpn` | حذف یک یوزر |
| `/pending` | درخواست‌های پرداخت در انتظار تایید |
| `/backup` / `/restore` | بک‌آپ‌گیری و بازیابی |
| `/setovpn` | جایگزینی فایل کانفیگ OpenVPN |
| `/stats` | آمار کاربران ربات |

## دستورات عمومی (همه کاربران)

| دستور | توضیح |
|---|---|
| `/addvpn` | شروع خرید اکانت VPN |
| `/tutorial` | آموزش اتصال L2TP/OpenVPN |
| `/myaccounts` | اکانت‌های VPN خریداری‌شده توسط همان کاربر |

## پشتیبانی از نسخه‌های مختلف RouterOS

ساختار User Manager بین نسخه‌های مختلف RouterOS 7.x کمی فرق دارد. این پروژه
روی نسخه‌هایی تست شده که اختصاص پروفایل از طریق `/user-manager/user-profile`
(نه فیلد مستقیم روی یوزر) انجام می‌شود. اگر با خطا مواجه شدید، با
`/user-manager profile print` و `/user-manager user-profile print` روی خود
روتر بررسی کنید که نام پروفایل‌های وارد‌شده در `/settings` دقیقاً مطابق
پروفایل‌های واقعی روی روتر شما باشد.

## مدیریت به‌روزرسانی

```bash
cd bot-mikrotik
git pull
sudo bash install.sh
```

اجرای مجدد `install.sh` فایل `.env` موجود را دست‌نخورده نگه می‌دارد و فقط
کتابخانه‌ها و سرویس را به‌روزرسانی می‌کند.
